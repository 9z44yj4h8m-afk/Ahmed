# Ahmmed — أطلس البث

واجهة ويب عربية RTL لتصفح قائمة قنوات M3U السعودية وتشغيل البث المباشر المتوافق مع المتصفح. تتضمن القائمة المضمّنة 54 قناة، مع بحث وتصنيفات وفلاتر فيديو/إذاعات وأزرار للقناة السابقة والتالية والصوت وملء الشاشة، كما تسمح باستيراد قائمة M3U أخرى.

## تشغيل المعاينة

شغّل خادم ملفات ثابتة على المنفذ 3000 من مجلد المشروع:

```sh
python3 -m http.server 3000 --directory public --bind 0.0.0.0
```

ثم افتح الصفحة على المنفذ 3000. يستخدم مشغل HLS مكتبة hls.js من jsDelivr في المتصفحات التي لا تدعم HLS مباشرة. تختلف قابلية تشغيل الروابط حسب صلاحية المصدر والمنطقة الجغرافية وسياسات CORS والمتصفح.

## الملفات

- `public/index.html` — بنية الواجهة.
- `public/styles.css` — التصميم المتجاوب.
- `public/app.js` — تحميل M3U والفلاتر والتحكم بالبث.
- `public/sa.m3u` — قائمة القنوات السعودية العربية.
- `public/manus-routes.json` — بيان المسارات.
